# ZANKAI AI (Gemini + installable app)

## Phone se setup
1. aistudio.google.com par free Gemini API key banao.
2. Ye saari files (bina folder ke) GitHub repo mein upload karo.
3. render.com -> New -> Web Service -> repo chuno.
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Environment: `GEMINI_API_KEY` = tumhari key
4. Deploy hone ke baad link Chrome mein kholo -> menu -> "Install app" / "Add to Home Screen".
5. APK chahiye to pwabuilder.com par apna link daalo.

Key kabhi `public/` ya GitHub code mein mat daalna.
